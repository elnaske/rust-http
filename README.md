# rust-http

This repository contains an implementation of the multithreaded web server project from [Ch. 21](https://doc.rust-lang.org/stable/book/ch21-00-final-project-a-web-server.html) of the [Rust book](https://doc.rust-lang.org/stable/book/title-page.html).

## Usage

Use `cargo run` to build the project and start the server.

The server will be bound to port 7878.

Open `127.0.0.1:7878` in your browser to access it.
